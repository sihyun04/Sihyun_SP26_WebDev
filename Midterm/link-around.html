Overview

Link ARound is an Augmented Reality interface designed to control and connect IoT devices through spatial interaction. Rather than relying on smartphone applications, the project explores a new way of managing smart home devices directly within the physical environment. By visualizing device connections in AR space, the system allows users to intuitively understand and configure automation workflows without navigating complex menus or rule-based interfaces.

The project focuses on improving the interaction between humans and physical objects in smart environments. Instead of designing another visual interface on a screen, we aimed to design an interaction model where users can directly manipulate relationships between devices in space.

Problem

The number of IoT-enabled devices in homes is rapidly increasing. However, the methods used to control and configure these devices have not evolved at the same pace. Most smart home systems rely on smartphone applications, where users must unlock their phone, open an app, and navigate multiple menus even for simple actions such as turning on a light.

Through research into existing smart home platforms such as Apple, Samsung, and Google, we identified three major usability issues. First, device control still depends heavily on mobile applications, making interactions slow and inconvenient. Second, there is a disconnect between digital interfaces and the real-world environment. Flat icons on a screen do not reflect where devices actually exist, making it difficult for users to understand what they are controlling. Third, setting up automation often feels like programming rather than managing a home environment. Rule-based logic can be difficult for non-expert users to understand, which prevents many users from fully utilizing smart home automation features.

These problems highlight a fundamental limitation of current IoT interfaces: they are not spatially intuitive, and configuring device connections often feels unnecessarily complex.

Solution

To address these challenges, we proposed Link ARound, an AR-based interaction system that enables users to connect and control IoT devices directly in physical space. Augmented Reality allows the interface to move beyond flat smartphone screens and place digital controls within the user's environment.

Instead of configuring automation through abstract logic rules, users can visually connect devices together. For example, rather than writing a rule such as "If the door opens, then turn on the lights," users can simply link the door object to the light object in AR space. By transforming automation logic into visible spatial relationships, the system reduces cognitive load and allows users to understand device connections more easily.

Design Principles

To guide the design process, we established three core principles.

First, Intuitive Linking. Device connections should feel natural and require no programming knowledge. Users should be able to create automation flows simply by connecting objects in space.

Second, Spatially Aware Interaction. The interface should reflect the real-world location and appearance of devices, allowing users to interact with them where they physically exist.

Third, Reduced Cognitive Load. Instead of requiring users to memorize automation logic, the system should visualize connections so that users can easily understand how devices interact.

Interaction Design

The interaction system is based on gaze and gesture inputs using AR glasses. In the default mode, no interface appears in the user's view, allowing the device to function like normal glasses without visual clutter. When a user looks at a device and performs a grab gesture, a translucent version of the selected device appears above the user's hand, enabling control through a floating interface.

The system also includes a palm menu, which appears when users look at their hand and perform a simple gesture. This menu provides an overview of all IoT devices in the home, displays which devices are currently active, and allows users to access editing features.

In Edit Mode, users can create automation workflows by directly connecting devices in AR space. By gazing at a trigger device, grabbing it, and releasing the gesture toward another device, users can visually create a connection between them. The system then allows users to configure conditions such as "if," "then," "and," or "or," enabling more complex automation flows. These connections appear as visible lines between devices, making the structure of automation workflows easy to understand at a glance.

Users can also modify existing flows by performing a scissor gesture to cut connection lines. This interaction mimics the physical act of cutting a wire, making the action intuitive and easy to understand.

Value

Link ARound provides several benefits compared to existing smart home interfaces. By reflecting the real-world location of devices, the system leverages spatial memory and makes interactions more intuitive. The visual connection of devices also simplifies automation logic, allowing even non-expert users to create and manage smart home workflows.

Gesture- and gaze-based interactions further provide a more natural method of controlling digital systems within physical environments. As AR devices become more widely adopted, such interaction models may replace smartphones as the primary interface for managing smart environments.
